# 社内規程AI検索 無料サンプル

登録した資料が検索され、回答の根拠として使われるかを、架空の社内規程で試す教材です。提供：なぎ。

**すべて架空の検証用資料です。実在企業の規程や法令の説明ではありません。** FAQと正式文書の不一致を意図的に含みます。

## ダウンロードと開始方法

[無料サンプル v0.1 ZIPをダウンロード](dist/policy_search_free_sample_v0.1.zip?raw=true)

1. ZIPを展開し、`README.txt`と`GUIDE.txt`を読みます。
2. Difyのナレッジには`upload_only`内の6文書だけを登録します。
3. `SYSTEM_INSTRUCTION.txt`をLLMのSYSTEM欄に設定します。
4. `QUESTIONS.txt`の質問を1つずつ新しい会話で試します。
5. ガイドに従って分割・取得件数を変更し、検索結果と回答を比較します。

ZIP全体や手順・質問をナレッジに登録しないでください。サービスの利用枠・料金は別途ご確認ください。

文書内の`EXC-2`などは、ファイル内の該当箇所を探すための識別子です。例えば`EXC-2`は「事前承認例外表」の予約前の承認・提出内容、`EXP-1`は「経費精算手順」の期限を示します。

## 試せる範囲と限界

2026年9月30日のDify Cloud Sandbox／Chatflow／gpt-5-miniの検証記録に基づきます。Difyのビルド番号・詳細モデルパラメータは未記録です。

- 代表3問を分割・検索設定の変更前後で試す体験版です。
- 分割方法と取得件数を同時に変更するため、改善原因を一方だけに限定できません。
- 1文書1チャンクは短い資料での対策であり、長文への万能策ではありません。
- 同じ検索結果・回答・時間を保証しません。必要な文書が取得されない場合もあります。
- 新規環境での本パッケージの追試と第三者による追試は未実施です。資料・手順の静的確認を実施しています。
- 更新検証用資料、全質問・期待回答・採点表、内部ログは含みません。
