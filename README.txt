社内規程AI検索 無料サンプル v0.1
作成日：2026-09-30／公開版

目的：登録した内容が検索され、回答の根拠に使われるかを、架空の短い資料で試す。
すべて架空の会社・制度による検証用資料です。実在する企業の規程、法律、税務の説明ではありません。
FAQの「2週間」と正式文書の期限の不一致を意図的に含めています。誤記として修正せず、正式文書の優先順位を確認する教材として使用してください。

【最初にすること】
1. ZIPを展開します。
2. GUIDE.txtを読みます。
3. AIに登録するのはupload_onlyフォルダ内の6つのtxtだけです。
4. SYSTEM_INSTRUCTION.txtはLLMのSYSTEM欄に貼ります。資料として登録しません。
5. QUESTIONS.txtから質問を1つずつ、新しい会話へ貼ります。
README、GUIDE、質問、利用条件やZIP全体をナレッジに登録しないでください。

【収録内容：全11ファイル】
upload_only/TRV_v1.txt：出張旅費規程 1.0
upload_only/EXP_v1.txt：経費精算手順 1.0
upload_only/ELG_v1.txt：雇用区分別対象条件 1.0
upload_only/EXC_v1.txt：事前承認例外表 1.0
upload_only/FAQ_v1.txt：FAQ・問合せ先 1.0
upload_only/REG_v1.txt：文書台帳 1.0
README.txt：収録一覧、試せる範囲、限界
GUIDE.txt：Difyへの登録、接続、比較、確認手順
SYSTEM_INSTRUCTION.txt：検証で使用した共通指示
QUESTIONS.txt：E05・E12・E02の3問のみ
USE_TERMS.txt：利用条件

【試せる範囲】
初期6文書だけで、承認手続、精算期限の不一致、申請項目の検索、文書名・版の追跡を確認できます。
旧新版混在や旧版削除後の判定は対象外です。それにはTRV v2・CHG v1・REG v2等が必要ですが、この配布物には含めません。
内部評価ログ、全質問、期待回答一覧、採点表、更新検証用資料、実行用コード、実際の回答ログ、アカウント情報・認証情報は収録していません。

【再現性と限界】
2026-09-30のDify Cloud Sandbox／Chatflow／gpt-5-miniの検証記録に基づく手順です。Difyのビルド番号と詳細モデルパラメータは記録していません。
同じ資料・指示・設定で試せますが、同じ検索結果・回答文・回答時間になるとは保証しません。画面、モデル提供、利用枠は変更される場合があります。
分割方法と取得件数を同時に変更しました。改善の原因を一方だけに限定する検証ではありません。
1文書1チャンクは今回の短い文書での対策であり、長文への万能策ではありません。
設定変更後の各代表質問は1回答ずつの記録です。変更後の反復検証や第三者の追試は未実施です。
この配布パッケージ自体を新規環境へ登録する追試は未実施です。収録ファイルと手順の静的確認まで行っています。
本サンプルの利用だけで実際の社内AIの導入可否、安全性や正確性を保証するものではありません。
